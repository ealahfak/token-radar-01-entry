Token launch radar: ranks 198 protocols from the sealed DefiLlama snapshot by an implied value fitted from the snapshot's own tokenized protocols (market-cap-per-TVL by category), separates pre-token from already-tokenized, and gives each protocol a concrete six-step farm plan with cost and time. The dashboard sorts and filters, shows the math per row, and needs no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
